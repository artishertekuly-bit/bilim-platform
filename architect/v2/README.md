## Іргелі шекара

- Tutor мен Examiner — екі бөлек сервис. Бір жүйе жазған деректі екіншісі ешқашан оқымайды. Эстафеталық көпір жоқ.
- Ортақ болатыны тек үшеу: оқу режиміндегі оқулық корпусы (LightRAG + `chunk_meta`), кітапхана ретіндегі инфрақұрылым (LLM gateway, кіріс сүзгісі) және мұғалімнің бір дабыл кірісі. Бұлар екі жүйе арасындағы дерек алмасу емес ([ortaq-infraqurylym.md §1](ortaq-infraqurylym.md)).
- Сабақтар — үшінші бөлек аймақ: баға бермейді, LightRAG корпусына қосылмайды, Tutor мен Examiner оларды оқымайды ([platforma-kartasy.md §3.2](platforma-kartasy.md)).
- Ойындар — төртінші бөлек аймақ: өз сұрақ банкі бар, нәтижесі ресми бағаға кірмейді ([geimifikatsiya.md](geimifikatsiya.md)).

## Ашық тәуекелдер

1. **ЖИ бағасының сапасы әлі өлшенбеген.** Алтын жиын дайын болғанша бұл — болжам ([ortaq §6](ortaq-infraqurylym.md), D16).
2. **Түйіндер мен алғышарт жиектерін тазалау** — офлайн қол жұмысы, көлемі белгісіз ([personarag §2.1](lightrag_personarag.md)).
3. **Шың сәттегі генерация шығыны.** Сұрақ банкінің көлемін бір мезгілде қатар жүрген сессиялардың ең көп саны анықтайды ([examiner §5.4](ai_examiner.md)).
4. **Е3-тегі «сол сәттегі толтыру».** Gateway-де генерация тек Batch API арқылы жүреді, ал Batch нәтижесі бірнеше сағатқа созылуы мүмкін. Сессия алдындағы жедел генерацияға бөлек синхрон маршрут керек пе — 4-қадамда шешіледі ([examiner §5.4](ai_examiner.md)).
5. **6–9-сынып кітаптарында тарау жоқ.** Чанк тақырыптарында «Тарау:» тек 5-сыныпта бар, сондықтан басқа кітаптарда «Тарау» масштабы әзірге қолжетімсіз (D58).
